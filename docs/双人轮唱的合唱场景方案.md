# 基于 ZegoExpressEngine SDK 实时合唱能力的双人轮唱场景方案

## 场景说明
多个用户，在一个业务房间内，分成两个小组（比如A，B），演唱同一首歌，A 组先开始演唱，在歌曲的某一个时间点，演唱人员由 A 组切换到 B 组

## 核心需求

### 同步性

#### 同时开始
即参与演唱的所有用户，在某种程度上应该是同时开始的（需要将网络延时纳入考虑范围内），

#### 进度与歌词同步
在整个演唱的过程中，参与演唱的这些用户应该也是同步的 -- 最简单的衡量办法， 未参与演唱的用户（即观众）听到的演唱的人声应该是保持一致的
同时，所有用户本地显示的歌词应该也是同步的（歌词本身也是受进度驱动）

#### 人声与伴奏同步
即演唱的人声，应该与伴奏是处于歌曲相同的位置

### 平滑过渡
在切换的过程中，需要确保在听众的角度，听到的歌曲的是不会受到影响的，切换的小组之间，也没有进度上明显的差异，整个切换的过程应该是平滑的

#### 基于 ZegoExpressEngine SDK 的采集音频数据回调和自定义音频采集实现人声复用

``` Objective-C
// 辅路流：自定义音频前处理，获取经过处理后的人声数据，再通过音频外部采集的能力，将数据重新给到 SDK
ZegoCustomAudioProcessConfig *customConfig = [[ZegoCustomAudioProcessConfig alloc] init];
customConfig.channel = ZegoAudioChannelMono;
customConfig.sampleRate = ZegoAudioSampleRate48K;
customConfig.samples = 0;
[self.engine enableCustomAudioCaptureProcessing:YES config:customConfig];
// 同时开启音频外部采集接口，
ZegoCustomAudioConfig *audioConfig = [[ZegoCustomAudioConfig alloc] init];
audioConfig.sourceType = ZegoAudioSourceTypeCustom;
[self.engine enableCustomAudioIO:YES config:audioConfig channel:ZegoPublishChannelAux];
[self.engine setAudioSource:ZegoAudioSourceTypeCustom channel:ZegoPublishChannelAux];
```

#### 同时推两路流与进度对齐配置

```Objective-C
// 主路流：使用 SDK 采集，ZegoMediaPlayer enableAux将伴奏与人声混音
// 开启主路流推流对齐能力
[self.engine setStreamAlignmentProperty:ZegoStreamAlignmentModeTry channel:ZegoPublishChannelMain];

ZegoPublisherConfig *pMainConfig = [[ZegoPublisherConfig alloc] init];
pMainConfig.forceSynchronousNetworkTime = YES;
// 主路推流
// 这里的 StreamID 建议有一定的生成规则，如 uid_roomid_chorus
[self.engine startPublishingStream:@"uid_roomid_chorus" config:pMainConfig channel:ZegoPublishChannelMain];

// 开启推流对齐能力
[self.engine setStreamAlignmentProperty:ZegoStreamAlignmentModeTry channel:ZegoPublishChannelAux];

ZegoPublisherConfig *pAuxConfig = [[ZegoPublisherConfig alloc] init];
pAuxConfig.forceSynchronousNetworkTime = YES;
// 这里的 StreamID 建议有一定的生成规则，如 uid_roomid_voice
[self.engine startPublishingStream:@"uid_roomid_voice" config:pAuxConfig channel:ZegoPublishChannelAux];

// 将音频前处理回调的数据通过音频外部采集接口给到辅路流
- (void)onProcessCapturedAudioData(unsigned char *)data dataLength:(unsigned int)dataLength param:(ZegoAudioFrameParam *)param timestamp:(double)timestamp {
    // 对应前面 enableCustomAudioCaptureProcessing
    // 收到回调以后，直接将数据通过接口给到 sdk
    [self.engine sendCustomAudioCapturePCMData:data dataLength:dataLength param:param];
}
```
